# 参考サイト分析：airback.store

- 確認日：2026-11-08
- 確認ページ：トップ `/`、商品ページ `/products/original-matt-black`
- 確認方法：PC（1440×900）とスマホ（iPhone 13相当、390×664）でブラウザ表示し、スクリーンショットを撮って computed style を取得
- 参考サイトのロゴ・写真・文章・独自グラフィックは流用していません。参考にしたのはレイアウトと情報設計だけです。

## 1. ファーストビュー
| | 参考サイト | TKselectへの反映 |
|---|---|---|
| トップ | 全幅のスライドショー（PCは高さ約800px、暗めの商品写真）。左寄せの見出し、1行のサブコピー、赤いCTAボタン。下部にメディア掲載ロゴの帯 | 全幅ヒーロー（IMG-12）＋左寄せのブランドコピー＋CTA2つ。暗いトーンは引き継ぎつつ、セール訴求はしない。メディア掲載ロゴは実績がないので載せない |
| 商品ページ | PCは左に縦並びサムネイル＋大きい商品画像（約半分の幅）、右に購入情報の2カラム。スマホは画像の直後にカートボタンを固定表示 | PCは画像55%／購入パネル45%の2カラム（パネルは追従）。スマホでは画像の直後から固定購入バーを出す |

## 2. 商品写真の配置と大きさ
- 一覧は4列のカード（正方形で背景はオフホワイト）。商品ページのメイン画像は正方形で、PCでは約700px。
- 機能説明では、写真と文章を左右に分けたブロック（約60:40）と、画像付きの3列カードを使っている。
- 反映：メイン画像は正方形で大きく見せる。比較・収納構造・シーンの写真はコンテナ幅いっぱい（最大1280px）か2分割で使う。

## 3. 横幅・余白・グリッド
- コンテンツ幅は約1340px（左右50pxの余白）。セクションの上下余白は約100〜140px。
- 反映：最大1280px＋可変ガター（スマホ16px〜PC48px）。セクションの上下余白は72〜136px、グリッドの間隔は16〜32px。

## 4. 文字
- 欧文グロテスク（Neue Haas Grotesk）。見出しは**weight 300で32〜40px**、本文は16px（スマホ15px）。ジャンプ率は控えめで、細いウェイトが上質感を出している。
- 反映：Inter＋Noto Sans JP。見出しはサイズを抑え、字間を広めに（0.06〜0.12em）。本文は16px、行間1.9（和文に合わせて広め）。

## 5. 色
- 背景は白、文字は #121212、パネルは暖色寄りのオフホワイト。アクセント（セール・カート）は赤 #B10000。
- 反映：指定のブランドカラーを使う。背景 #F7F7F4、パネル #EDEDE8、アクセント #5B6C5D。購入ボタンはセージグリーンにし、赤のような煽り感は避けた。

## 6. 画像と説明文の組み合わせ
- 「How it works」：番号付き3ステップのテキストと大きな写真を、薄い色のパネルにまとめている。
- 「Benefits」：上に写真、下に見出しと本文を置いたカード。
- 比較表：自社製品／圧縮袋／パッキングキューブを ✓ と × で比較。
- 反映：使い方3ステップ（写真3枚）、3つのメリット（アイコンカード）、圧縮前後を左右に並べて比較。他社製品と比べる表は、実測データがない段階では作らない。

## 7. スクロールに伴うセクション展開（商品ページ）
購入エリア → 実際の利用者の写真カルーセル → 受賞ロゴ → アコーディオン（Features／Description／Specifications／Shipping）→ メディアロゴ → How it works → 比較表 → Benefits → FAQ → 関連商品 → AIによるレビュー要約 → フッター

**課題**：PCでは、機能・仕様・配送の情報が右カラムのアコーディオンにまとめられていて、幅が狭い。
→ TKselectでは右カラムを購入に必要な情報だけにし、ほかは全幅のセクションとして縦に並べた（依頼にあった「BASEの細い右カラムを避ける」とも一致）。

## 8. 特徴・ベネフィットの伝え方
- 数字（"up to 50% more space"、"25+ items"）、アイコン付きのチップ、受賞ロゴ、レビュー数で信頼感を出している。
- 反映：数字は**実測するまで出さない**。代わりに「実測中」のバッジと、検証が済んだ項目数（0/9）を表示し、実測で正直に伝えるブランドの姿勢そのものを信頼の材料にする。レビューや受賞ロゴは載せない。

## 9. 購入ボタン・価格の配置
- 価格（定価に取り消し線）→ カラーのスウォッチ → オプション → 特徴チップ2×2 → バンドル選択 → 全幅の大きいカートボタン → 3つの安心アイコン（100日返品／送料無料／世界配送）。
- 反映：価格 → カラー・モデル → 特徴チップ2×2 → 全幅の購入ボタン → 安心アイコン3つ（配送／返品／決済。中身は確定後に差し替え）。取り消し線の定価やバンドルは使わない。

## 10. スマホの購入導線
- 商品画像のすぐ下にカートボタンを固定表示（`mobile-float-button`）し、その直下に安心アイコンを並べる。
- 反映：購入ボタンが画面から外れたら下部に固定購入バー（商品名・価格・ボタン）を出し、最後の購入セクションが見えている間は隠す。PCでは購入ボタンを通り過ぎてから出す。
